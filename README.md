A small program that writes one short text (100 characters) to `/output/entry.txt`: the excuse a robot vacuum gives after eating a sock — the sock was lying face-down, dressed as dust, and never once said "not food", so the vacuum filed it under lunch.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

No network, no model calls, deterministic output — the same bytes on every run.
